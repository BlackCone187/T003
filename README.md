# T003
ENCS3320 socket programming project

## Configuration

Edit `config.json` to set the TCP port, HTTP port, log file, and maximum clients.

## Running

Start the server by typing in terminal:

```bash
python run_server.py
```

start the client in another terminal:

```bash
python run_client.py
```

Open the web server:

```text
http://localhost:6462
```

## Testing

Test the client using:

* Ping
* Tracert
* Nslookup
* Ipconfig
* Route
* ARP
* Nestat

check `log/server_log.json` to verify that requests are logged.
